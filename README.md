# PyLot - Miniature Autonomous Car

> This project focuses on developing a miniature autonomous car system using image processing and machine learning techniques.

## Main Features

- **Road Edge Detection**: Applied Canny filtering and Hough Transform to detect road edges and generate a steering line for autonomous navigation.
- **Road Sign Detection**: Built a road sign recognition system with **99% accuracy** using **TensorFlow** and **OpenCV**.

## Project Structure

- **1-frame-processing**: Image frame processing for feature extraction.
- **2-video-processing**: Video sequence processing for dynamic detection.
- **3-data-learning**: Supervised learning from collected datasets.
- **4-deep-learning**: Implementation of deep learning models for improved detection and navigation.
- **5-transfer-learning**: Application of transfer learning to boost model performance on limited data.
